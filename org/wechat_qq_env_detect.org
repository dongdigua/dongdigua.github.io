strace 一下
#+BEGIN_SRC sh
strace -f -o wechat.strace -s 255 flatpak run com.tencent.WeChat

有意思:
#+BEGIN_EXAMPLE
execve("/bin/sh", ["sh", "-c", "--", "/usr/bin/lsblk -a -n -d -i -r -o name,type,serial,model"]

#+END_EXAMPLE

com.tencent.WeChat 4.1.0.13 不执行 =ip= 了，但还执行 =lsblk=
